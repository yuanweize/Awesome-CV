# Job Search Platforms Reference

> Compiled from 102 application records in `meta/applications/`.
> Last updated: 2026-09-29.

This document catalogues every job-search channel encountered during the application
campaign, grouped by platform type. Statistics reflect actual usage counts from
`source_url` and `official_url` fields across all `application.yaml` manifests.

---

## Platform taxonomy

| Type | Description |
|---|---|
| **Aggregator** | Multi-employer job boards; browse and apply on-site or redirect to company ATS |
| **ATS / Career Portal** | Employer-owned applicant tracking system or career page |
| **Staffing / Recruitment** | External recruiters and staffing agencies with their own portals |
| **Direct / Spontaneous** | Company website or email; no standardised job portal |
| **Niche / Academic** | Sector-specific boards (robotics, aerospace, startups) |

## Tactical notes for the Czech market

### High-yield channels (recommended focus)
1. **StartupJobs.cz** — Best ROI for Prague-based tech startups; supports
   profile-based discovery and proactive outreach.
2. **LinkedIn Jobs** — Essential for international companies and hybrid/remote
   roles; "Easy Apply" reduces friction but often redirects to an ATS.
3. **Jobs.cz / Cocuma** — Broadest CZ coverage; many employers white-label
   Jobs.cz for their ATS.

### ATS awareness
Most large employers use third-party ATS platforms (Greenhouse, SmartRecruiters,
Workday, Lever). The source URL may be LinkedIn or a board, but the actual
application lands on the ATS. Track both `source_url` (discovery channel) and
`official_url` (submission endpoint) in `application.yaml`.

### Agency considerations
Staffing agencies (Reed, Manpower, Randstad, Adecco) can unlock unlisted roles
but add an intermediary. Useful for initial market entry or when a company's
direct portal is inaccessible.

### Spontaneous / direct applications
For small companies (Siesta Labs, Flying Rat Studio, Carebot), there is often
no formal portal. Research founders on LinkedIn, prepare a targeted pitch
(`portal_note.md`), and apply via email or LinkedIn InMail.

## Maintaining this document

When adding a new application via the standard `application.yaml` workflow:
1. If the platform is already listed above, no action needed.
2. If it is a **new platform**, add it to the appropriate section with domain,
   market, and initial usage count.
3. Run a periodic audit: `grep -rh source_url meta/applications/*/application.yaml`
   to refresh counts.
