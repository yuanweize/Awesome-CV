# Local Portfolio asset policy

This tracked file documents directory semantics only. It must not list a user's projects,
screenshots, employers, infrastructure, or approved recruiter assets.

- `raw-private/`: private originals and evidence; always local and ignored.
- `raw/`: compatibility location for existing private originals; local and ignored.
- `curated/`: user-specific recruiter-reviewed derivatives; still local and ignored.
- `generated/`: user-specific diagrams; still local and ignored.
- `examples/assets/`: synthetic or explicitly public-safe assets used by public demos.
- `meta/evidence/portfolio/ASSET_INDEX.md`: optional private, detailed user asset index.
- `archive/assets/portfolio/`: private superseded derivatives with provenance notes.

“Recruiter-safe” is not the same as “safe to publish in Git.” Before sharing any visual,
inspect pixels, metadata, embedded PDF objects, licences, and current Git tracking state.
An image never becomes factual authority; claims still require the canonical registry.
