# JD analysis

Analyse before drafting. Preserve the complete JD and record:

1. **Role identity:** exact title, actual role family, seniority, and the balance among
   engineering, support, operations, and field work.
2. **Core responsibilities:** the three to five duties likely to dominate normal work.
3. **Must-haves:** hard technical, language, location, travel, qualification, and legal gates.
4. **Nice-to-haves.**
5. **Signals:** ATS-relevant tools and domain language that can be used truthfully.
6. **Risks:** real gaps or mismatches, without recruiter-facing self-rejection prose.
7. **Evidence map:** each important requirement -> eligible claim ID -> Golden CV section
   or project -> Portfolio case/page -> confidence.

Use four confidence labels:

- `STRONG MATCH`: direct, current, defensible evidence.
- `SUPPORTED MATCH`: clear evidence with a narrower context or scale.
- `ADJACENT / TRANSFERABLE`: a real nearby capability with an explicit bridge.
- `REAL GAP`: no defensible evidence.

Do not use `only`, `just`, `limited`, `merely`, `basic`, or `hobby` as reflexive
disclaimers. Use precise scope labels when accuracy requires them. Evidence depth may
limit claim strength; it should not erase a relevant completed action.
